Export calendar

Download your JX events and recurring schedules as an ICS file to import into another calendar app. This is a one-time export, not automatic synchronization.

  • Includes every event: one-time events, repeating series, and the dates you changed or cancelled.
  • Tasks are not included.
  • Times are exported exactly as entered (9:00 stays 9:00). The app you import into shows them in its own time zone.
  • Changes you make in JX later won’t update the imported copy. Export again if you need a fresh copy.

Backup & restore

Back up

Save a complete copy of your JX Calendar data, including events, recurring schedules, exceptions, tasks and settings.

The file contains your personal calendar. Keep it somewhere safe and private.

Restore

Select a previous JX backup to validate and restore your calendar data.

You’ll see what the backup contains before anything is changed.
